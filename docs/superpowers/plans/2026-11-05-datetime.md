# Date Pickers (alumina-datetime in corundum's look) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give apps alumina-datetime's calendar, date, period, time and timestamp pickers
as `gui::datetime`, with a config that uses corundum's Lucide icons and `tr!` words in
English and Japanese, and weeks fixed to start on Monday.

**Architecture:** The `datetime` feature re-exports alumina-datetime 0.2 and adds three
functions: `config(ctx)`, `icons()` and `labels(ctx)`. alumina draws its colours from
`ui.visuals()`. That includes the selection, which `theme::install` sets from the accent,
so the theme needs no code. `DayBadge` is a counting callback and takes no colours, so
there are no colour helpers either.

**Tech Stack:** Rust 2024, egui 0.37, alumina-datetime 0.2 (which uses chrono), and
Lucide SVGs.

**Spec:** `docs/superpowers/specs/2026-11-05-text-markdown-pdf-datetime-design.md`,
section "3. Date pickers". The branch is `feat/datetime`, stacked on
`feat/markdown-preview` (PR #121). This work has no issue yet; open it with the PR.

## Global Constraints

- **Feature:** `datetime = ["dep:alumina-datetime"]` with `alumina-datetime = "0.2"`, off
  by default. The umbrella crate has `datetime = ["gui", "corundum-framework-gui/datetime"]`.
  The default build gains no dependency, and `cargo deny check` passes.
- **First weekday:** always Monday, because the week numbers are ISO. This is the
  person's decision. Sunday weeks wait for sapphire-turtle/alumina#36. Say so in the
  module doc.
- **Words:** every word goes through `tr!`, with keys in both
  `crates/corundum-framework-gui/locales/{en,ja}/corundum.ftl`, named
  `corundum-datetime-*`. Egui id strings never start with `corundum-`, because the i18n
  test reads such strings as Fluent ids.
- **Lucide icons:** they follow #100's convention, with the white stroke used in
  `list.svg`, a `pub fn` in `icons.rs`, and an entry on the demo's Icons screen. Fetch
  each from `https://raw.githubusercontent.com/lucide-icons/lucide/main/icons/<name>.svg`.
  If a name has moved, find the current one, as #100 did for `letter-b`.
- **CI:** clippy `-D warnings --all-targets` is clean for the gui crate with
  `--no-default-features`, and with `--no-default-features --features datetime`. Add
  `datetime` to the loops in `.github/workflows/ci.yml:46` and in both loops of
  `mobile-ci.yml`.
- **Commits:** conventional, ending with
  `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Do not edit `CHANGELOG.md`.

## Review Focus

1. **Labels in Japanese.** The months and weekdays must be in alumina's order, January to
   December and Monday to Sunday, not Sunday first. Test: Task 1 `japanese_words_in_alumina_s_order`.
2. **The config follows a language switch.** A context switched from en to ja gives
   Japanese labels at the next `config(ctx)` call, so nothing is cached for good. Test:
   Task 1 `the_config_follows_the_language`.
3. **The week-number column.** With `show_week_numbers(true)` on top of `config(ctx)`, the
   column still shows, because Monday is first. Test: Task 1
   `week_numbers_show_with_corundum_s_config`, which draws a `Calendar` and finds the
   column heading.

### Task 1: `datetime`: `gui::datetime` with corundum's config

**Files:**
- Create: `crates/corundum-framework-gui/src/datetime.rs`, and the SVGs listed below
- Modify:
  - `crates/corundum-framework-gui/{Cargo.toml,src/lib.rs,src/icons.rs}`;
  - both `.ftl` files;
  - the umbrella crate's `Cargo.toml`, `src/lib.rs` and `tests/features.rs`;
  - `README.md` and `README.ja.md`;
  - CI: `ci.yml` and `mobile-ci.yml`;
  - `demo/src/screens/icons.rs`.

**Interfaces:**
- **Icons.** `previous` → new `chevron_left()` (Lucide `chevron-left`). `next` → the
  existing `chevron_right()`. `today` → new `calendar_check()` (Lucide `calendar-check`).
  `clear` → the existing `x()`. `now` → new `clock()` (Lucide `clock`).
- **`gui::datetime`:**
  ```rust
  pub use alumina_datetime::*;
  /// The calendar's buttons as corundum's Lucide icons.
  pub fn icons() -> CalendarIcons;
  /// Every word the pickers show, in the context's language.
  pub fn labels(ctx: &egui::Context) -> Labels;
  /// corundum's look for the pickers: its icons and words, weeks from Monday (ISO numbers).
  /// Build it each frame or when the language changes; it is cheap.
  pub fn config(ctx: &egui::Context) -> CalendarConfig;
  ```
  `CalendarIcons`, `Labels` and `CalendarConfig` are `#[non_exhaustive]`. Build them from
  `Default::default()` and set their fields, or use `CalendarConfig`'s builder methods
  (`labels`, `icons`, `first_weekday`). Check alumina's
  `crates/alumina-datetime/src/labels.rs` for the exact methods.
- **Strings** (en / ja), keys `corundum-datetime-<name>`:
  - **Months:**
    - `month-1` … `month-12`: January … December / 1月 … 12月.
    - `month-short-1` … `month-short-12`: Jan … Dec / 1月 … 12月.
  - **Weekdays:** `weekday-mon` … `weekday-sun`: Mo Tu We Th Fr Sa Su / 月 火 水 木 金 土 日.
  - **`week-column`:** W / 週.
  - **Period kinds:**
    - `day`: Day / 日
    - `week`: Week / 週
    - `month`: Month / 月
    - `year`: Year / 年
    - `range`: Range / 期間
  - **Buttons:**
    - `today`: Today / 今日
    - `now`: Now / 現在
    - `clear`: Clear / クリア
    - `previous`: Previous / 前へ
    - `next`: Next / 次へ
  - **Tooltips:**
    - `choose-month`: Choose a month / 月を選ぶ
    - `choose-year`: Choose a year / 年を選ぶ
  - **Times of day:** `am`: AM / 午前. `pm`: PM / 午後.
  - **`none`:** — / — (an em dash in both).
  - **`period-hint`:** `2026-11-03, 2026-W45, 2026-11, 2026 …` in both, since the format is
    the same in both.
- **The module doc:**
  - Colours follow the visuals, and corundum's theme sets the selection from its accent.
  - Use `config(ctx)` with alumina's widgets.
  - Weeks start on Monday, and why (with a link to alumina#36).
  - Timestamps are `chrono::NaiveDateTime`, so the app converts time zones.
